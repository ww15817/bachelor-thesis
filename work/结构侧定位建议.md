# 结构侧定位：三条路，选哪条

日期：2026-11-04。给 P1-6 / P1-7 的决策用。

## 摆着的事实

- 20λ 口径（10 GHz 下 D = 600 mm）、铝板 2 mm、只算自重：中心挠度约 0.1 mm = 0.0033λ，增益掉 **0.008 dB**。图上根本看不出来
- 要掉 0.5 dB 得 0.81 mm 的变形，是自重量级的八倍
- 随机表面误差**不会抬高第一副瓣**（实测 −18.51 → −20.95 dB，越差越低），所以「副瓣抬高」不能当卖点

也就是说：按现在的算例和载荷，结构那半边做完了也没故事。

## 三条路

### A. 放大口径

把算例抬到 100λ 或 200λ。口径大了，同样厚度的面板挠度按 a⁴ 涨，变形量级立刻够。

代价：全波对照做不了（openEMS 跑 100λ 口径不现实），而「用 GO/PO 省内存」这个立题本来就是因为电大尺寸——口径越大，立题越站得住。

但题目写死了「统一 20λ 算例」，改口径等于改题。

### B. 参数化研究（推荐）

不绑定具体结构。给定表面误差 rms 从 0 扫到 0.06λ，给出增益曲线和反解表，定位成**灵敏度分析**：这台天线对面板公差有多敏感、公差该定到什么水平。

数据已经有了：`work/scan_surface_error.py`、`work/表面误差扫描.md`、`work/Ruze增益损失表.md`。

好处：不用改题、不用改口径，20λ 算例保留，全波对照也保留；论文里这块写成「接口已通、以灵敏度分析验证」，诚实而且站得住。

坏处：不是「我算出了一个真实天线的变形」，是「我给出了这条链路的响应曲线」。答辩时可能被问「真实结构呢」。

### C. 换主指标

不只看增益，看指向误差、波束偏移、远角旁瓣。可能对小变形更敏感。

代价：要先算出来才知道敏不敏感，工作量不确定；而且远角旁瓣要改算法（现在只有逐点方向图）。

## 我的建议

**B 为主，A 的后半留一句话。**

主算例保持 20λ，结构侧按参数化处理，正文明说「20λ 口径配典型面板公差，增益变化在 0.01 dB 量级，故本文以灵敏度曲线而非单点结果呈现」。这不是回避，是把量级讲清楚——审的人反而会觉得你算明白了。

口径那一句可以放「展望」：若要观察 0.5 dB 量级的退化，需要 100λ 以上口径或更大载荷，那时 GO/PO 的省内存优势才真正兑现。

这样：立题不变、算例不变、诚实、有故事（故事是「我量化了敏感性」而不是「我算出天线会掉 0.5 dB」）。
