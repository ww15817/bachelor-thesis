## 项目是什么

反射面天线仿真。20λ 卡塞格伦天线，链路是：openEMS（FDTD 全波）算馈源 → 自研 GO/PO 积分算远场 → FEniCSx 算面板变形 → 变形折成口径相位误差回代。

口径场幅度模型：

    A(θ) = g(θ) · cos²(θ/2) / (M·F)

其中 `g(θ) = cos^q(θ)` 是馈源电压方向图，`q` 是馈源波束宽度参数。

## 任务

写**一个函数**：给定馈源边缘照射角 `theta_edge` 和期望的边缘锥削 `target_db`（dB），解出对应的 `q`。

数学关系（写代码前先自己核一遍）：

    锥削比 = A(θ_edge) / A(0) = cos^q(θ_edge) · cos²(θ_edge/2)
    目标   = 10^(target_db/20)
    ⇒ q = ln(目标 / cos²(θ_edge/2)) / ln(cos(θ_edge))

函数名 `q_for_edge_taper`，放在 `src/go_po/feed.py`。

## 实现要求

- `theta_edge` 必须在 (0, π/2) 开区间，否则抛 `ValueError`
- 若 `目标 / cos²(θ_edge/2) > 1`，锥削为正、物理上做不到，抛 `ValueError` 并把两个数写进异常消息
- 返回 float
- docstring 写明公式来源和推导
