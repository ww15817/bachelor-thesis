# ISSUE-017 的解法：三条路

现在 `src/fenics/plate_bending.py` 用双泊松串联解 Kirchhoff 板，中心挠度比 Navier 级数低 **5.4%**，而且不随网格收敛（40×40 是 −5.57%，80×80 是 −5.43%）。是方法误差。

## 根因

简支边的边界条件是

    w = 0,   M_nn = 0     （法向弯矩为零）

我施的是 `M = 0`（弯矩和为零）。板内 `M = M_nn + M_ss`，两者只在轴对称且 M_t=0 时才相等，方板/圆板一般不等。所以整条解偏低，且加密网格不会好转。

## 三条路

### A. 耦合双场（Kirchhoff 混合形式）

把 `w` 和弯矩（或曲率）同时当未知场，弱形式里两者一起出现，边界条件直接施 `w=0` 和 `M_nn=0`。这是 Kirchhoff 板的经典混合形式（HHJ 那一类）。

- 好处：物理正确，四阶方程原样解
- 代价：需要非协调元或额外正则化才能稳定，dolfinx 没有现成例子，自己搭要调参数
- 判断：**不划算**。为了一个 5.4% 的修正，投入可能比整条结构链路还多

### B. Reissner–Mindlin（一阶剪切板）

三个场：`w`、`θx`、`θy`，都是 C0，dolfinx 的向量拉格朗日元直接能做。剪切项用 MITC4 或减缩积分避免锁定。

- 好处：生态成熟，能算固支/简支/自由边，以后要算真实面板也用它
- 代价：`t/a` 很小（600 mm 口径、2 mm 厚是 1/300）时锁定很强，得认真处理；而且它本身是另一套理论，跟 Kirchhoff 的差别要另外交代
- 判断：**如果结构侧要往深里做，选这条**，但它不是「修个边界条件」，是换模型

### C. 接受近似，把误差写进论文

把现在的双泊松定位成「近似板模型」，明写：简支边按 `M=0` 处理，中心挠度偏低约 5.4%，误差来自边界条件的近似而非离散。

- 好处：零额外投入，链路已经通了，数字也有了
- 代价：审稿或答辩会问「为什么不施 M_nn=0」，得答得上来
- 判断：**眼下最合适**。结构侧本来就是灵敏度分析定位（见 `work/结构侧定位建议.md`），5.4% 的系统偏差在一个「量级估算」里不致命；而且只要把这句话写在模型假设里，它就是诚实的

## 建议

按 **C** 走，同时把 B 列为「后续工作」。理由：

1. 结构侧现在要回答的是「变形到什么量级增益才明显」，这个问题的答案是「0.03λ 量级」，5.4% 的模型偏差不影响结论
2. 真要更高精度，Reissner–Mindlin 是更自然的下一步，而不是硬啃 HHJ
3. 论文的「假设与局限」那一节本来就要写模型边界，这条正好放进去
