**1. 卡塞格伦几何逐量复算**（不复用仓库自带断言）：

`r1+r2−z_main = 12.8 = F+2a` 精确成立；`feed_half_angle_for_edge = 17.7613°`。

**2. 口径幅度守恒链**：`ρ = 2MF·tan(θ/2)` 复算到 **5.3e-15**，
因此 `dA/dΩ = (MF)²/cos⁴(θ/2)`，`A = g·cos²(θ/2)/(MF)` 无误。
这条链是 C-11 修复的地基，值得在论文里作为推导写出来。

**3. 「溢出计为损失」的口径论证**（论文可直接引用的一句话）：
馈源在主面顶点时，主面上任意点从顶点看的极角 ≥ arctan(R/z_rim) = **72.65°**，
而副面只占 0~17.76°。所以溢出功率里 17.76°~72.65° 的部分**直接从口径边缘外漏掉**，
72.65°~90° 的极少部分打在主面上、按镜面反射散射到大角度（我用 72.6° 入射算过反射向，
约偏离视轴 46°）。两者都不进主波束、但都在 `P_rad` 里——
按方向性 `D = 4πU_max/P_rad` 把溢出全部计为损失是**自洽的**，不是近似偷懒。

**4. 效率公式的解析判例**：均匀口径 + 中心遮挡 η 时，
`|∫un|²/(A·∫un²)` 手推给出 `1−b` 精确值（教科书遮挡口径），
正是 C-11 要求的性质；q=8 锥削口径数值 0.9482 与之相容。

## 三、新发现

### C-18 | 中 | src/antennasim/pipeline.py:80（`_aperture_from_rays`）

**口径边缘锥削诊断量系统性偏亮约 0.08 dB。**

表尾是 `np.append(avg, avg[-1])`——把最外环（θ = 25.5/26·θe，ρ≈0.98R）的幅度
**常数外推**到 R；而且 θ 中点采样 `(i+0.5)/n·θmax` 永远到不了 θe。
于是打印的「口径边缘锥削 −1.83 dB」实际是 **0.98R 处**的值。

解析真值（幅度模型本来就是 θ 的解析函数）：

```
A(θe)/A(0) = cos^(q/2)(θe)·cos²(θe/2) = cos⁴(17.7613°)·cos²(8.8807°)
           = 0.8029  →  −1.906 dB          （q=8, 20λ 算例）
代码打印                                    −1.832 dB
偏差                                        +0.074 dB（边缘偏亮）
```

**影响**：对增益数字可忽略（外 2% 环带面积 3.9%、幅度误差 <0.5%，η 变动 <0.001 dB），
但这个数以「边缘锥削」的名义进了 `STATUS`（−1.8）、`work/复核清单`（−1.83）、
`work/coupled_demo.py` 的 `EDGE_TAPER_DB = -1.83`，论文里若写
「q=8 的边缘照射为 −1.8 dB」，复算者用 cos⁴ 公式会得到 −1.9 dB，差 0.1 dB 说不上来源。

**修法**（5 行）：表尾补一个解析点，别用外推值——

```python
theta_edge = float(feed_half_angle_for_edge(geo))
edge_amp = float(feed_pattern(np.array([theta_edge]))[0]
                 * np.cos(theta_edge / 2.0) ** 2 / (geo.M * geo.F))
return np.append(uniq, geo.R), np.append(avg, edge_amp)
```

`m3_cassegrain.py:79-80` 是同一份代码，同步改。改完 −1.83 → −1.91，
`coupled_demo.py` 的 `EDGE_TAPER_DB` 跟着改成 −1.91（对它 −0.018 dB 的结论影响 <0.001 dB）。
