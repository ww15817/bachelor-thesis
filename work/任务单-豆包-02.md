## 任务：做一张 Ruze 增益损失表

这是一个反射面天线毕设。链路是 openEMS 算馈源 → 自研 GO/PO 算远场 → FEniCSx 算面板变形 → 变形折成口径相位误差回代。

现在要回答一个卡住整个结构侧的问题：**面板变形要多大，增益才看得出来掉？**

## 要用到的公式（仓库里已经定了口径，别自己重新推）

口径相位误差 rms 与表面变形 rms 的关系：

    σ_φ = 2·k·σ_w = 4π·σ_w/λ        （k = 2π/λ，σ_w 是表面位移 rms）

Ruze 增益损失（**注意是 exp(-σ_φ²)，不是 exp(-σ_φ²/2)**；这条口径 2026-11-04 刚修过）：

    G/G₀ = exp(-σ_φ²)
    损失(dB) = 10·log₁₀(exp(-σ_φ²)) = -4.343·σ_φ²

## 要产出的东西

写一个脚本（放 `work/` 下，随便叫什么，比如 `work/ruze_table.py`），用 numpy 算，**不要手算**，输出一张 markdown 表，落到 `work/Ruze增益损失表.md`。

表格至少要有这些列：

| σ_w (λ) | σ_w (mm) @10 GHz | σ_φ (rad) | G/G₀ (dB) |

- `σ_w/λ` 从 **1/500 扫到 1/20**（0.002 → 0.05），取 10 个左右的点，密度自己定但要能看出趋势
- `λ = 30 mm`（10 GHz，对应 20λ 口径 D = 600 mm）
- 表下面再加三行反解：要掉 **0.1 dB / 0.5 dB / 1.0 dB**，各自需要多大的 σ_w（给 λ 和 mm 两种单位）

再写一段 200 字以内的解读，说清：按 20λ（600 mm）口径、铝板两毫米厚、只算自重的量级（中心挠度约 0.1 mm），落在表里的哪一行、掉多少 dB；以及要看到 0.5 dB 得把变形放大到多少。

## 验收（必须自己跑过，把输出贴上）

1. `σ_φ = 0.5 rad` 那一点，损失应为 **−1.086 dB**（±0.01）。这是 `-4.343 × 0.25`，手算能核
2. 表里 `σ_w = 0.004λ`（0.12 mm）那一点，`σ_φ` 应为 0.0503 rad
3. 反解出来的数代回正算，能复现 0.1 / 0.5 / 1.0 dB（误差 < 0.001 dB）
