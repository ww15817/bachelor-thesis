# 第 1 章 绪论

> 正文草稿。文献依据全在 `docs/06-反射面开源链路文献核查.md`，题录都核过 DOI。

## 1.1 背景

反射面天线是卫星通信、射电天文、深空探测的主力形式。电大尺寸（几十到几百个波长）带来的问题是：**仿真成本随口径的平方涨**。

商业软件（CST、HFSS、GRASP）能算，但有两个门槛：授权费用，和内存。一个 100λ 的反射面做全波，网格按 λ/20 算就是上亿单元——普通工作站跑不动。

开源世界里，这三件事其实各有成熟的工具：

- 小尺寸全波：openEMS
- 电大尺寸高频近似：PO 类开源包（PyPO 等）
- 结构有限元：FEniCSx、CalculiX

问题在于——**没有人把它们串起来**。

## 1.2 国内外研究现状

按三种做法分。

### 方法链：混合全波与高频近似

把全波和高频近似接起来的思路不新：

- Noga & Topa（EuCAP 2010）做了混合全波/高频近似的框架
- Le Lepvrier 等（IEEE TAP 2014）用 DG-FDTD + IPO 做级联
- ICMMT 2012 有单反射面的 PFDTD-PTDPO 组合
- 中文文献里，毛钧杰（电子学报 2002）做过抛物面的 FDTD 与 PO 分析

这些工作的共同点：**代码自研**，没有开源实现。

### 结构-电磁耦合

面板变形影响电性能这条线，西电那一系做得最成体系：

- Zhang Shuxin 等（IEEE TAP 2013）：用 FEM 的同形函数把位移插值到积分点，逐单元折成相位误差再进远场积分——这是本文第 6 章方法的直接来源
- Li Pu 等（IEEE APM 2012）：40 m 天线 + 7.3 m 卡塞格伦的验证算例
- Wang Wei 等（中国科学 2023）：双反射面 PO 相位误差，2.2 m 算例——**方法上最贴本文**

这些工作用商业软件或自研代码，同样没有开源实现。

### 商业链：唯一有实测验证的完整样板

- Du 等（PASP 2016）：CST 全波 + GRASP-10 算 PO + 实测孔径效率，GRASP 偏高 6.5%、全带误差 3%
- Valente 等（IEEE Access 2024）：GRASP + CHAMP 3D 做整条光路

这是唯一「全波 + PO + 实测」都齐的样板，本文的验证范式照它。

### 开源单点

- openEMS（Liebig 等，IJNM 2012）：FDTD 求解器本体。**它的 54 篇被引文献里没有一篇做反射面或 PO 混合**
- PyPO（Moerman 等，JOSS 2023）：GO + PO，能导入外部波束
- PAOS（SPIE 2024）：注意这是**光学** POP（Fresnel/paraxial），不是射频反射面
- Dual Reflector Designer（Zenodo）：开源 PO/PTD，有收敛测试，但没有结构耦合

### 小结

**空白在「开源」这一维。** 方法层面每一段都有出处，串起来这条路没有人发表过。

（检索边界：OpenAIRE / OpenAlex 题录层对 `openEMS + PO`、`openEMS + reflector` 全部零命中；IEEE、CNKI 正文大多打不开，中文只有题录。所以「没有」指索引范围内没有，非索引期刊和学位论文不排除。）

## 1.3 本文工作

**目标**：用三个开源工具串成一条完整的反射面分析链路，每一段都能对上解析解或教科书公式。

链路：

```
openEMS（FDTD 全波）算馈源  →  自研 GO/PO 算远场  →  FEniCSx 算面板变形
                                       ↑                        │
                                       └──── 变形折成相位 ←──────┘
```

**四道验证闸**（第 4 章）：

| 闸 | 判据 | 实测 |
|---|---|---|
| 几何 | 共焦 + 等光程 | 4.4e-16 / 7.1e-15 |
| 幅度 | `ρ = 2MF·tan(θ/2)` | 5e-15 |
| 积分器 | 解析 Airy | 7.0e-06 |
| 结果 | 遮挡场幅比 vs 教科书 | 0.04 dB |

**三个主要结论**：

1. **原算例的馈源配置是错的**：q=8 时 64% 功率溢出副面，代价 4.49 dB；换到 q≈50 可回收 3.65 dB（第 5 章）
2. 全波馈源验证了解析假设的合理性（E 面几乎正中 `cos^8`），但暴露了轴对称假设的局限（H 面差 3.8 dB）
3. **结构侧只能定位成灵敏度分析**：20λ 口径配自重只有 0.01 dB 级，要看到 0.5 dB 需面板公差压到 0.81 mm（第 6 章）

# 第 2 章 理论基础

> 正文草稿。这一章只放「后面要用到的东西」，不铺开讲天线理论全貌。
> 每一节的结尾都点一句「这个式子在第几章用」。

## 2.1 为什么用高频近似

反射面天线的口径通常是几十到几百个波长。全波方法（FDTD、FEM）在这个尺度上受内存限制——网格密度按 λ/20 算，一个 100λ 的反射面要上亿个单元。

高频近似的依据是：当结构尺度远大于波长时，局部的场可以用射线描述。几何光学（GO）给出射线的路径与幅度，物理光学（PO）把口径上的场积分成远场。代价是失去绕射效应（边缘衍射、后瓣），在近轴主瓣区影响很小。

本文的算例是 20λ 口径，GO/PO 已经足够；也正是因为口径大，GO/PO 才有意义。这个取舍写在第 3 章的工具分工里。

## 2.2 卡塞格伦的几何关系

双反射面由主面（抛物面）和副面（双曲面的一支）组成，两者共焦。

主面：`z = ρ²/(4F)`，口径半径 `R`。

副面用双曲面的实半轴 `a` 和半焦距 `c` 表示：

    a = (M−1)(F−L)/2
    c = (M+1)(F−L)/2
    e = c/a = (M+1)/(M−1)

其中 `M` 是放大率，`L` 是副面顶点到主面顶点 的距离。

**共焦条件**：近焦点在 `z = F`。这是定义性要求，也是第 4 章第一道验证闸的判据。

**等光程**：每条射线从远焦点出发、经副面和主面反射后，`r1 + r2 − z_main` 必须是常数，理论值 `F + 2a`。这条同样是第 4 章的判据，而且比共焦更强——它同时约束两条曲线的形状。

## 2.3 口径场的幅度：一个容易写错的式子

这一节的结论是第 4、5 两章的地基。

馈源发出的球面波经两次反射后到达口径。要算口径上的幅度，需要「能量守恒」这个约束：同一束射线管内的功率在传播中不变，所以

    |A|² dA = |g|² dΩ

其中 `g` 是馈源的电压方向图，`dΩ` 是立体角元。

关键在于 `dA/dΩ`。对**单抛物面**，焦点到反射面的距离是 `r = F/cos²(θ/2)`，于是 `1/r` 的扩散给出经典结果。但**双反射面不能照抄**——射线的等效扩散距离不是 `r1 + r2`。

正确的做法是从口径半径与张角的关系出发。卡塞格伦可以等效成一个焦距为 `M·F` 的抛物面，于是

    ρ = 2·M·F·tan(θ/2)

对 θ 求导：`dρ/dθ = M·F/cos²(θ/2)`，加上面积元的 `ρ dρ`，整理得

    dA/dΩ = (M·F)² / cos⁴(θ/2)

代入功率守恒：

    A(θ) = g(θ) · cos²(θ/2) / (M·F)

**这个式子的检验方式**：旧版写的是 `g/(r1+r2)`，边缘锥削给 −3.59 dB；新式给 −1.83 dB；而解析值 `cos⁴(θe)·cos²(θe/2)` 给 −1.91 dB。旧式差 1.7 dB，新式差 0.08 dB（网格外推的残留）。

这条推导值得在论文里完整写一遍——它是后面所有增益数字的来源。

## 2.4 口径远场积分

口径上的场分布为 `A(ρ,φ)`，远场由 Kirchhoff 积分给出：

    E(θ,φ) = ∫∫ A(ρ,φ) · exp(j k ρ sinθ cos(φ−φ₀)) · ρ dρ dφ

对均匀照明，这个积分有解析解（Airy 图案 `2J₁(u)/u`，`u = kR sinθ`）。这是第 4 章第三道闸的判据。

## 2.5 方向性与效率

方向性的定义是

    D = 4π U_max / P_rad

其中 `P_rad` 是**全部**辐射功率。写成口径场的积分形式：

    D = 4π |∫A dA|² / (λ² ∫|A|² dA)

注意分母是 `∫|A|²`，不是 `(∫A)²/A`。这个区别在第 4、5 章会反复出现——用错了会把遮挡算两遍。

口径效率拆成三项：

    η = η_spill × η_ap

- `η_spill`：馈源打到副面的功率比例，`1 − cos^(q+1)(θ_edge)`
- `η_ap`：口径上的效率，分子分母都只取未遮挡区

**溢出为什么算损失**：溢出的功率确实辐射出去了，但落在 17.76°~90° 的大角度上，不贡献轴向的 `U_max`，只进分母。按上面的定义，它必须算损失。

## 2.6 面板变形与相位

表面位移 `w` 会让光程改变 `2w`（往返各一次），于是口径相位扰动

    dφ = 2k·w = 4πw/λ

**Ruze 公式**：随机面板误差下

    G/G₀ = exp(−σφ²)

其中 `σφ` 是相位误差的 rms（弧度）。

**适用条件**：相位误差是随机的、相关长度远小于口径。确定性变形（比如整板挠曲）不满足这个条件——第 6 章会给出 15% 的偏差，那里必须用 PO 直接积分。

## 2.7 本章小结

四样东西：

1. 几何：共焦 + 等光程（第 4 章验证）
2. 幅度：`A = g·cos²(θ/2)/(M·F)`（第 4、5 章的增益来源）
3. 方向性：`D = 4π|∫A|²/(λ²∫|A|²)`（第 4、5 章的效率预算）
4. 相位：`dφ = 4πw/λ` + Ruze（第 6 章）

其余理论（绕射、边缘效应）本文不涉及，属于模型边界的范畴，写在第 7 章。

# 第 3 章 开源工具链与集成架构

> 正文草稿。这一章讲「三个工具怎么分工、为什么这么分、怎么串起来」，不讲软件安装步骤（那些放附录）。

## 3.1 分工的依据

三个工具不是随便挑的，分工依据是**频率尺度**：

| 工具 | 方法 | 适合的尺度 | 在本链路的角色 |
|---|---|---|---|
| openEMS | FDTD 全波 | 几λ | 算馈源（喇叭、波导、销钉） |
| 自研 GO/PO | 高频近似 | 几十到几百λ | 算反射面远场 |
| FEniCSx | 有限元 | 结构（跟波长无关） | 算面板变形 |

这样分的原因：

- 馈源是**小尺寸、细节多**（波导壁厚、销钉、台阶），全波能算准，高频近似算不准
- 反射面是**大尺寸、形状简单**（旋转对称的双曲面/抛物面），高频近似够快，全波算不动
- 结构是**另一门物理**，跟电磁完全解耦，只需要一个接口把位移传过去

这个分工本身就是这篇论文的立题：商业软件把三件事绑在一起卖，开源世界里三件都能找到，但**没人把接口接上**。

## 3.2 openEMS：馈源侧

openEMS 是 FDTD 求解器，用 CSXCAD 建模、用 `nf2ff` 做近远场变换。

本文用的是**销钉馈电的角锥喇叭**：WR-90 矩形波导 + 后短路板（距销钉 λg/4）+ 同轴销钉激励 TE10，喇叭四壁用斜面旋转而成。

两条踩过的坑值得记：

1. **`AddRectWaveGuidePort` 的 `a/b` 必须传米**，不是毫米。传毫米等于告诉它「22.86 米宽的模式」，端到端失配，`Prad` 会一直是 `1e-38` 量级
2. **喇叭斜面旋转符号写反**会把四面朝内收成封闭角锥，表现是 S11 ≈ 0 dB、能量困在腔内缓慢衰减

这两条写进 `examples/openems/README.md` 的踩坑表了。它们的共同点：**报错信息不指向真正的原因**——`Prad≈0` 看起来像激励问题，实际上是几何问题。

## 3.3 自研 GO/PO：反射面侧

分两步：

1. **射线追踪**：从馈源发出射线束，依次打到副面、主面，算出落点、方向和光程
2. **口径积分**：把射线结果转成口径幅度分布，再对口径做 Kirchhoff 积分

第 1 步的理论依据是第 2 章的几何关系；第 2 步的幅度模型是第 2 章那个 `A = g·cos²(θ/2)/(M·F)`。

**为什么自己写而不是用现成的 PO 包**：现成的 PO 包（PyPO、PAOS）面向的是通用的反射面形状，而卡塞格伦的射线追踪需要双曲面求交、共焦校验、遮挡处理这些特定逻辑；自己写反而短。

## 3.4 FEniCSx：结构侧

用双泊松串联解 Kirchhoff 板（细节在第 6 章）。导出 `x/y/w` 三个数组，供耦合链路插值。

**接口设计**：结构侧的输出是一个 npz 文件，字段是散点坐标和位移。这样电磁侧不需要知道有限元的网格、单元类型、求解器参数——只要有坐标和位移就能插值。

这个接口是「松耦合」的：可以换成任何结构求解器（CalculiX、deal.II、甚至解析解），电磁侧一行都不用改。本文实际用了解析圆板和 FEniCSx 方板两种，验证了这一点。

## 3.5 集成：一条命令

整条链路用 YAML 配置驱动：

```yaml
feed:
  source: npz                      # 或 analytic
  file: data/feeds/horn_10ghz_a80b60.npz
  plane: E

structure:
  enabled: true
  file: data/feeds/plate_deflection_2mm.npz
  lambda_m: 0.030
```

一条命令 `run_pipeline.py cases/xxx.yaml` 跑完五个阶段：建模几何 → 射线追踪 → 构造口径场 → 远场积分 → 保存结果。

**可复现性**：把仓库里已跟踪的文件导出一份到空目录，测试全过（58 条），算例逐位一致。这条验证过（台账 W-0028）。

## 3.6 环境：两条路

- **Windows 原生**：openEMS 官方预编译包（zip 里带 cp313/cp314 的 wheel），解压即用。注意 Python 3.8 之后必须 `os.add_dll_directory` 指向 openEMS 目录，只加 PATH 一定报 `DLL load failed`
- **WSL**：源码编译，适合需要改 openEMS 本身的场合

FEniCSx 在 conda 环境里（`dolfinx 0.11.0`）。两套环境通过文件交换数据，不共享内存。

## 3.7 本章小结

三件事：

1. 分工依据是频率尺度，不是软件偏好
2. 集成方式是**配置文件驱动 + 文件交换**，各模块之间只认数据格式，不认实现
3. 可复现性验证过：干净目录里测试全过、算例逐位一致

这一章的价值在于说明「集成」不是把三个程序拼在一起，而是**设计出三个干净的接口**：馈源→PO 的方向图接口、结构→PO 的位移场接口、配置→全流程的参数接口。

# 第 4 章 射频链路实现与验证

> 这是**正文草稿**，不是提纲。数字都来自仓库，能重算。
> 写的时候按论文语气改，别照抄这里的口语。

## 4.1 本章要回答什么

一条高频近似链路，最怕的是「跑通了但不知道对不对」。所以本章不按代码结构组织，按**判据**组织：四道独立的验证闸，每一道都有一个能解析算出来的基准。

四道闸按「从几何到远场」的顺序：

1. 几何对不对 —— 卡塞格伦共焦条件
2. 场强对不对 —— 口径幅度守恒
3. 积分器对不对 —— 均匀口径 vs 解析 Airy
4. 结果对不对 —— 遮挡的场幅比 vs 教科书

## 4.2 几何：共焦条件

卡塞格伦双反射面的定义性条件是：副面（双曲面的一支）与主面（抛物面）共焦，使得从远焦点发出的球面波经两次反射后变成平面波。

用双曲面的实半轴 `a` 与半焦距 `c` 表示，近焦点位置必须是

    z_near = F

射线追踪的结果是 `4.4e-16`（相对 `F = 8λ`），即机器精度。

更强的判据是**等光程**：每条射线的 `r1 + r2 − z_main` 必须等于常数。理论值是 `F + 2a = 12.8λ`，实测起伏 `7.1e-15λ`。

这两条一起，说明几何建模没有引入误差——不是「差不多对」，是精确。

## 4.3 口径幅度：双反射面的能量守恒

这一节是整条链路的地基，也是修过两次的地方。

单抛物面的口径幅度是 `A ∝ g(θ)/r`，因为馈源发球面波（`1/r` 扩散）而反射面保持射线管功率。**双反射面不能照抄这个式子**——等效扩散距离不是 `r1 + r2`，而是 `M·F`。

推导的起点是口径半径与馈源张角的关系：

    ρ = 2·M·F·tan(θ/2)

数值验证到 `5e-15`。于是面积元与立体角之比

    dA/dΩ = (M·F)² / cos⁴(θ/2)

功率守恒 `|A|²dA = |g|²dΩ` 给出

    A(θ) = g(θ) · cos²(θ/2) / (M·F)

这一步的验证方式是「换一个幅度模型，看边缘锥削怎么变」：旧模型 `g/(r1+r2)` 给 `−3.59 dB`，新模型给 `−1.83 dB`，而解析值 `cos⁴(θe)·cos²(θe/2)` 给 `−1.91 dB`。旧模型差 1.7 dB，新模型差 0.08 dB——这 0.08 是网格外推带来的（后来也修了）。

## 4.4 积分器：均匀口径 vs 解析 Airy

口径远场用 Kirchhoff 积分

    E(θ) = ∫∫ A(ρ,φ) · exp(j k ρ sinθ cos(φ−φ₀)) · ρ dρ dφ

对均匀照明，这个积分有解析解（Airy 图案 `2J₁(u)/u`）。

数值与解析的最大绝对偏差 **7.0e-06**，第一零点位置 `3.4950°` 对理论 `3.4963°`。

这条闸的意义：它同时验证了网格采样、相位因子、面积元三件事。任何一处写错，偏差都不会是 `1e-06` 量级。

## 4.5 结果：遮挡的两个数

副面遮挡是卡塞格伦的固有代价。遮挡面积比 `4.913%`，但**「遮挡损失」有两个不同的数**，这是本章最容易写错的地方：

| 口径 | 公式 | 数值 |
|---|---|---|
| 场幅比 | `20log10(1−ε)` | −0.437 dB（实测 −0.48） |
| 功率（增益） | `10log10(1−ε)` | −0.219 dB（实测 −0.234） |

实测值比解析值略大，因为被挡掉的正好是照明最强的中心区域。

论文里必须写清用哪一个。写「遮挡增益损失 −0.48 dB」会被按方向性定义复算的人抓住差 0.26 dB——多了个平方。

## 4.6 绝对增益预算

把三项并起来：

| 项 | 值 | 来源 |
|---|---|---|
| 理想均匀口径 `(πD/λ)²` | 35.96 dBi | 解析 |
| 溢出发射 | −4.49 dB | 馈源张角 17.76° vs 波束宽度 |
| 锥削 + 遮挡 | −0.22 dB | 未遮挡区二重积分 |
| **合计** | **31.24 dBi** | |

口径效率 `0.3372`。这个数偏低，主要不是数值问题，是**馈源配错了**——见第 5 章。

## 4.7 对照算例：改配置不换代码

除了 20λ（F/D=0.4），还做了一个 F/D=0.5 的对照算例，只改 YAML 里一行。

| 算例 | F/D | 遮挡比 | 口径场幅损失 | 绝对增益 |
|---|---|---|---|---|
| cassegrain_20lambda | 0.4 | 4.913% | −0.48 dB | **31.24 dBi** |
| cassegrain_fd05 | 0.5 | 4.551% | −0.44 dB | **29.65 dBi** |

fd05 比 20λ 差 **1.59 dB**。原因是 F/D 变大后副面张角变小（14.25°），溢出更多——和 20λ 的 17.76° 相比少了 3.5°。

这个对照说明两件事：一是参数化是真的（代码一个字没改），二是**副面张角对溢出极其敏感**——F/D 从 0.4 到 0.5，溢出损失从 4.49 dB 涨到 6.11 dB。这条为第 5 章的联合设计做了铺垫。

## 4.8 本章小结

四道闸的实测偏差分别是 `4.4e-16`、`5e-15`、`7.0e-06`、`0.04 dB`（遮挡），说明几何和积分器本身没有引入误差。真正限制精度的是模型选择（轴对称假设、网格台阶），不是算法。

这一节的写法建议：**先给判据，再给数字**，不要先讲代码结构。评审关心的是「你怎么知道它是对的」，不是「你怎么写的」。

# 第 5 章 馈源与副面的联合设计

> 正文草稿。这一章是全文最有分量的一节——它发现了算例配置本身的错误，而且给出了量化的改进空间。

## 5.1 一个被归一化藏起来的损失

第 4 章的效率预算里，理想增益是 35.96 dBi，实测只有 31.24。差的那 4.7 dB 里，最大一项不是遮挡、不是锥削，而是**溢出发射 −4.49 dB**。

这一项被漏掉的方式值得记一笔：口径场积分用 `∫A dA` 做归一化，而 `∫A dA` 只对**打到口径的那部分功率**求和。馈源打出去、但没打到副面的那 64%，从头到尾没有进入任何一个求和式。所以所有相对结论（增益损失、方向图对比）都是对的，但绝对增益少了一大块。

判据是几何的：馈源在主面顶点时，副面只占馈源的 0°~17.76°。用 cos^q 的功率方向图积分，

    η_spill = 1 − cos^(q+1)(θ_edge)

q=8、θ_edge=17.76° 时得 `0.3557`，即 **64% 的功率溢出**。解析式与数值积分差 `1.4e-06`，是可信的。

## 5.2 溢出功率去哪了

一个容易被问的问题：溢出的功率不也辐射出去了吗，为什么全算损失？

它确实在辐射，但**不进主波束**。按方向性定义 `D = 4πU_max / P_rad`，`P_rad` 包含全部辐射功率，而溢出的那份功率落在 17.76°~90° 的大角度上——17.76°~72.65° 直接漏到口径外，72.65°~90° 打在主面上、按镜面反射散射到离轴约 46° 的方向。两者都不贡献轴向场，所以都只能算分母里的功率，不能算分子里的 `U_max`。

这个论证不是近似偷懒，是方向性定义直接给出的。

## 5.3 q 扫描：最优是个平台

把 q 从 4 扫到 96，总增益：

| q | 溢出发射 | 总效率 | 绝对增益 |
|---|---|---|---|
| 8 | −4.49 dB | 0.3372 | 31.24 dBi |
| 16 | −2.49 dB | 0.5299 | 33.21 dBi |
| 32 | −0.97 dB | 0.7267 | 34.58 dBi |
| **47** | −0.44 dB | **0.7815** | **34.89 dBi** |
| 64 | −0.19 dB | 0.7713 | 34.84 dBi |
| 96 | −0.04 dB | 0.6790 | 34.28 dBi |

机理很清楚：q 加大让溢出降下来，但边缘锥削变深、口径效率跟着掉。两者在 q≈50 附近平衡。

**但最重要的不是那个 34.89，是它周边的样子。** q=47 与 q=64 只差 0.05 dB，q=32 到 64 整段都在 0.3 dB 内。也就是说这是个**平台**，不是一个点。

论文里必须按平台写——「q 取 40~70 均可，建议 50 左右」。给单点最优（「最优 q=47」）会引出「凭什么正好是 47」的质疑，而 0.05 dB 在任何模型不确定度之内，答不上来。

净收益 **+3.65 dB**，这是这个算例配置错误的量化代价。

## 5.4 全波馈源对照

解析 `cos^q` 只是模型。用 openEMS 算一个真实的销钉馈电角锥喇叭（WR-90 波导 + 阶梯/斜面喇叭，10 GHz），得到方向图后再拟合等效 q：

| 模型 | 口径 | Dmax | E 面锥削@17.76° | H 面锥削@17.76° |
|---|---|---|---|---|
| 销钉喇叭 | 80×60 mm | 13.21 dBi | −1.58 dB（q≈8.1） | −5.50 dB（q≈23） |
| 销钉喇叭 | 58×60 mm | 12.02 dBi | −1.37 dB（q≈6.8） | −2.99 dB（q≈11.7） |

这里有一个漂亮的巧合：流水线原来假设的 `cos^8`（17.76° 处 −1.70 dB），**几乎正中 80×60 喇叭的 E 面**（−1.58 dB）。但 H 面差 3.8 dB。

接进流水线后，E 面与 H 面给出的绝对增益分别是 31.25 与 31.13 dBi，只差 **0.12 dB**。原因还是那个：遮挡和溢出占主导，口径效率对锥削不敏感。

这个结论有两层意思：

1. 好消息——把解析馈源换成全波馈源，对这个算例的增益结论影响不到 0.12 dB，所以第 4 章的数字不怕换模型
2. 坏消息——矩形喇叭的 E/H 面不对称是真的（3.8 dB 锥削差），它会让主面方向图出现不对称，而流水线假设轴对称。这一条必须写进模型边界

## 5.5 本章小结

三件事：

1. 原配置的馈源是错的，64% 功率溢出，代价 4.49 dB；换到 q≈50 可回收 3.65 dB
2. 最优是平台不是点，按区间写
3. 全波馈源验证了解析假设的合理性（E 面几乎正中），但也暴露了轴对称假设的局限（H 面差 3.8 dB）

这一章的价值不在「算出 34.89」，在**发现算例配置本身有错，并且给出改正的代价**。审稿和答辩都会问「你怎么知道这个配置是对的」，这一章就是回答。

# 第 6 章 结构—电磁耦合

> 正文草稿。这一章的数据最薄，写法上要格外诚实：讲清「算到了什么程度」，别把量级估算写成精确预测。

## 6.1 这一章要回答什么

一个反射面天线，面板在自重、风压、温度下会变形；变形会改变口径上的相位；相位变了，增益和方向图就变。

要把这条路打通，需要三样东西：一个结构求解器、一个把变形折成相位的接口、一个能接住相位扰动的远场积分器。三样都有了之后，还要回答一个问题——**这个效应到底多大**。

## 6.2 结构求解：为什么用板弯曲，为什么用双泊松

面板可以当薄板。Kirchhoff 板的方程是四阶的 `∇⁴w = q/D`，直接解需要 C¹ 连续单元，而 FEniCSx 没有现成的板/壳单元。

办法是拆成两个二阶方程（混合形式）：

    M = −D∇²w        （弯矩和）
    ∇²M = −q         （平衡）

两个都是泊松，C0 拉格朗日单元就能解。

**但这套近似有一个明确的缺陷**：简支边的边界条件应该是 `M_nn = 0`（法向弯矩为零），而这里施的是 `M = 0`（弯矩和为零）。板上 `M = M_nn + M_ss`，两者不相等。后果是板变刚、挠度偏小：

| 几何 | 偏差 |
|---|---|
| 方板（边长 600 mm） | **−5.4%** |
| 圆板（直径 600 mm） | **−26.6%** |

而且**不随网格加密改善**（方板 40×40 → 80×80 只从 −5.57% 到 −5.43%）。所以这是模型误差，不是离散误差——论文里必须这么写，否则会被拿网格收敛来问。

正是因为圆板的 −26.6% 不可接受，本章的结构侧**定案用方形子板**。真实反射面板本来就是拼块的方形子板，这个选择反而更接近实际。

## 6.3 从变形到相位

口径上的相位扰动由光程差给出：

    dφ = 2k·w = 4πw/λ

变形场是散点（板网格节点），要插值到口径的极坐标网格上再折成相位。

验证链路真的生效的方法：把变形量放大 1/5/10/20 倍，看增益损失是否单调。

| 放大倍数 | 轴向场比 | 损失 |
|---|---|---|
| 1 | 0.99824 | −0.015 dB |
| 5 | 0.95651 | −0.386 dB |
| 10 | 0.83324 | −1.585 dB |
| 20 | 0.43712 | −7.188 dB |

单调，且 1 倍时与解析挠度版的 −0.018 dB 一致（差 0.003 dB，来自方板/圆板的几何差异）。链路可信。

## 6.4 两个独立方法，结论一致

**解析挠度版**（圆板，简支，均布载荷）：

    w(r) = q/(64D)·(a²−r²)·[(5+ν)/(1+ν)·a² − r²]

对 600 mm 口径、2 mm 铝板、自重 53 Pa：中心挠度 533 μm，`σ_w/λ = 0.0055`，PO 直接算得增益损失 **−0.018 dB**。

**有限元版**（方板，FEniCSx）：中心挠度 543.5 μm，`σ_w/λ = 0.0050`，损失 **−0.015 dB**。

两个独立方法给出同一个量级：**0.01 dB 级**。这个结论比任何一个单点结果都可靠。

## 6.5 Ruze 公式的适用边界

Ruze 给的是 `G/G₀ = exp(−σφ²)`。这一章里它出现在两个不同的场合，结论完全不同：

| 场合 | PO 直接算 | Ruze | 差 |
|---|---|---|---|
| 随机相位屏（相关长度远小于口径） | — | — | <1% |
| 圆板整体挠曲（低频、空间相关） | −0.018 dB | −0.021 dB | **15%** |

差别不在公式，在**前提**。Ruze 假设相位误差是随机的、相关长度远小于口径；而圆板挠曲是一个低频的确定性场，整片同向偏移。这种场对轴向场的抵消比随机场小。

所以论文里说清楚：**确定性变形一律用 PO 直接积分，Ruze 只留给随机面板误差**。

## 6.6 灵敏度：多大的变形才看得见

把表面误差从 0 扫到 0.06λ：

| σ_w/λ | 增益损失 | 第一副瓣 |
|---|---|---|
| 0.01 | −0.069 dB | −18.51 |
| 0.02 | −0.274 dB | −18.79 |
| 0.04 | −1.100 dB | −19.60 |
| 0.06 | −2.465 dB | −20.95 |

反解：掉 0.5 dB 需要 `σ_w = 0.027λ`（10 GHz 下 0.81 mm），是自重的约 8 倍。

这里还有一个反直觉的结论：**随机表面误差让第一副瓣下降，不是上升**。主瓣能量被打散，紧邻主瓣的第一副瓣先被削弱。要说「副瓣抬高」，得看远角的平均旁瓣电平，那是另一套算法。

（确定性变形是另一回事——第 6.5 节那个 ×10 的方向图对比里，副瓣确实从 −18 抬到了 −14。）

## 6.7 本章小结

三句话：

1. 结构 → 相位 → 远场的链路通了，两个独立方法都给出 **0.01 dB 级**的结论
2. 这个量级撑不起「结构变形导致性能退化」的叙事，所以结构侧只能定位成**灵敏度分析**
3. 板弯曲的 5.4% 是模型误差（不随网格收敛），Ruze 对确定性变形不适用（差 15%）——这两条必须写进模型边界

这一章最容易被问的一句话：「你这个 0.01 dB 有什么意义？」答案是：意义在于**给出公差要求**——要看到 0.5 dB，面板公差得压到 0.81 mm 以内，这是设计输入，不是仿真废品。

# 第 7 章 结果与讨论

> 正文草稿。这一章的核心是一句话：**哪些误差是数值的，哪些是模型的**。
> 材料在 `docs/08-误差账.md`，那里一张表列全了十二条。

## 7.1 精度账：哪些是真的准

先把「算法本身对不对」这件事说清。

| 环节 | 判据 | 实测偏差 |
|---|---|---|
| 均匀口径远场积分 | 解析 Airy | 7.0e-06 |
| 卡塞格伦共焦 | 近焦点 = F；等光程 | 4.4e-16 / 7.1e-15 |
| 口径幅度守恒 | `ρ = 2MF·tan(θ/2)` | 5e-15 |
| 溢出效率公式 | 数值积分 | 1.4e-06 |

这四个数字说明：**几何建模和积分器没有引入误差**。不是「差不多对」，是到机器精度。

真正限制精度的是两处，都不是算法问题：

- **遮挡台阶**：±0.01 dB（遮挡半径落在网格环之间，整个环被整体判给或判走，不随加密收敛）
- **轴对称假设**：0.12 dB（矩形喇叭 E/H 面锥削差 3.8 dB，接进流水线后增益只差 0.12 dB）

所以论文里写「约 −0.5 dB」而不是「−0.479 dB」，是有依据的。

## 7.2 模型账：哪些是近似

这一节比上一节重要，因为答辩会问。

| 近似 | 偏差 | 方向 | 能不能靠加密改善 |
|---|---|---|---|
| 板弯曲边界条件（方板） | −5.4% | 偏低 | **不能**（方法误差） |
| 板弯曲边界条件（圆板） | −26.6% | 偏低 | **不能** |
| Ruze 对确定性变形 | 15% | Ruze 偏大 | 不能（前提不符） |
| 轴对称假设 | 0.12 dB（增益） | 不定 | — |
| 边缘锥削诊断（已修） | 曾 +0.07 dB | 偏亮 | — |

三个要点：

**一、板弯曲那两行是模型误差，不是数值误差。** 证据：方板 40×40 → 80×80 只从 −5.57% 到 −5.43%。加密网格不改方法误差。

根因是简支边施 `M = 0` 而不是 `M_nn = 0`。圆板的环向弯矩很大，被硬压成零等于多加约束，所以偏差比方板大一个量级。

**这也是结构侧定案方板的理由**——圆板的 26.6% 不可接受。

**二、Ruze 不能当万能判据。** 同一个公式，随机相位屏下与 PO 差 <1%，确定性变形下差 15%。差别在前提，不在公式。

**三、模型误差的方向要写清。** 偏低 / Ruze 偏大 / 不定——写清了才能判断哪些结论是保守的。

## 7.3 与文献的对比

| 工作 | 方法 | 验证方式 | 误差量级 |
|---|---|---|---|
| Du 等（PASP 2016） | CST + GRASP-10 | 实测孔径效率 | GRASP 偏高 6.5%，全带 3% |
| Wang Wei 等（2023） | 双反射面 PO 相位误差 | 2.2 m 算例 | — |
| **本文** | openEMS + GO/PO + FEniCSx | 四道解析闸 | 算法 1e-06，模型 5.4% |

可以和 Du 那篇对比的一点：他们用实测验证，本文用解析验证。**解析验证的好处是能定位误差来源**（哪一段偏、偏多少），实测验证只能给总误差。

这不是说本文更好——实测是金标准，本文没有实测条件。这一点要在结论里说清。

## 7.4 模型边界

写论文最容易被漏的一节。四条：

1. **轴对称假设**：流水线的馈源方向图是 `g(θ)`，旋转对称。矩形喇叭不是。E 面和 H 面要分别算，两个结果差 0.12 dB
2. **薄板理论**：板弯曲用的是 Kirchhoff 板，`t/a = 1/300` 时适用；再厚就要换 Reissner–Mindlin
3. **Ruze 的前提**：随机、相关长度远小于口径。确定性变形不能用
4. **离散化精度**：遮挡台阶 ±0.01 dB；网格加密不改善

还有一条不算边界但要说：**没有实测数据**。这条写在结论里，别藏。

## 7.5 这一章想说明什么

一句话：**射频侧的数字可以拿去写论文，结构侧的数字只能当量级估算。**

依据是两条账：

- 射频侧的偏差都在 1e-06 以下（算法），或者 0.12 dB（模型选择）
- 结构侧的偏差是 5.4% 和 26.6%（模型），而且不随加密改善

这个区分不是自贬——它恰恰说明算明白了：知道哪些数能当真，哪些不能。

## 7.6 本章小结

三件事：

1. 算法精度到机器精度，限制精度的是模型选择（遮挡台阶、轴对称假设）
2. 结构侧有两处方法误差（板边界 5.4%/26.6%、Ruze 15%），都不随加密改善
3. 与文献对比：本文用解析验证，Du 2016 用实测验证，各有适用场合

**写作提醒**：这一章不要写「误差在可接受范围内」这种空话。要么给数字，要么说清方向（偏低还是偏高）。评审看的不是「小不小」，是「知不知道自己偏在哪」。

# 第 8 章 结论与展望

> 正文草稿。这一章只写三样：做成了什么、算出来什么、还有什么没做。
> 不写「本文具有重要的理论意义和实践价值」这种话。

## 8.1 做成了什么

**一条全开源的反射面天线分析链路**，一条命令跑完：

```
openEMS（FDTD 全波）算馈源  →  自研 GO/PO 算远场  →  FEniCSx 算面板变形
                                       ↑                        │
                                       └──── 变形折成相位 ←──────┘
```

三段之间的接口是：

- 馈源 → PO：方向图文件（npz，`theta/E_norm/Prad/Dmax`）
- 结构 → PO：位移场文件（npz，`x/y/w`）
- 配置 → 全流程：YAML

**可复现性**：干净目录里测试全过（58 条），算例逐位一致。

**四道验证闸**全部通过，偏差分别是 `4.4e-16`、`5e-15`、`7.0e-06`、`0.04 dB`。

## 8.2 算出来什么

三个主要结论：

**一、原算例的馈源配置是错的。** q=8 时馈源波束比副面张角（17.76°）宽出一大截，64% 的功率打在副面外面，折 −4.49 dB。这一项以前被 `∫A dA` 归一化吞掉了，账上完全看不到。

改用 q≈47 可回收 **3.65 dB**（31.24 → 34.89 dBi）。但 q=47 与 q=64 只差 0.05 dB，是个**平台**，论文里按「q 取 40~70 均可」写，不给单点最优。

**二、全波馈源验证了解析假设的合理性，也暴露了它的局限。** 销钉喇叭的 E 面（q≈8.1、−1.58 dB）几乎正中流水线假设的 `cos^8`（−1.70 dB）；H 面差 3.8 dB。接进流水线后增益只差 0.12 dB——因为遮挡和溢出占主导，口径效率对锥削不敏感。

**三、结构侧只能定位成灵敏度分析。** 20λ 口径配铝板自重，增益只掉 0.01 dB 级（两个独立方法：解析圆板 −0.018 dB、有限元方板 −0.015 dB）。要看到 0.5 dB，面板公差得压到 0.81 mm（0.027λ），是自重的约 8 倍。

这不是「算不出东西」，是**量级本身是结论**：20λ 这个尺度上，结构效应对增益的影响小于馈源配置错误带来的一阶效应。

## 8.3 还有什么没做

诚实列三条：

**一、没有实测数据。** 本文的验证全部是解析验证，没有实测孔径效率或方向图。Du 等（PASP 2016）用 CST + GRASP + 实测做过，那是有硬件条件下的金标准。本文不具备这个条件。

**二、结构侧的模型精度有限。** 板弯曲的双泊松近似有 5.4%（方板）到 26.6%（圆板）的方法误差，根因是简支边条件 `M = 0` 与 `M_nn = 0` 的差别。要修得换 Reissner–Mindlin 或耦合双场，本文没做。

**三、轴对称假设没有真正解决。** 矩形喇叭的 E/H 不对称，流水线用单一一维方向图近似。本文只量化了影响（0.12 dB），没有实现二维方向图。

## 8.4 展望

三条，按「值得做」排序：

1. **换 Reissner–Mindlin 板**：能同时解决方板/圆板的边界条件问题，让结构侧从「量级估算」升到「可用精度」
2. **支持二维馈源方向图**：把 `g(θ)` 换成 `g(θ,φ)`，代价是射线追踪和口径积分都要改成二维采样
3. **放大口径再验证**：100λ 以上口径，结构效应才会到 0.5 dB 量级，那时 GO/PO 省内存的优势才真正兑现。这也可以作为这条链路的下一个算例

## 8.5 一句话

这条链路的价值不在算法——每一段的方法都是现成的。价值在**把它们接起来，并且每一段都能对上解析解**。

公开文献里做这件事的（Du 2016、Wang Wei 2023）用的都是商业软件或自研代码；用开源工具串起来这条，检索范围内没见到。
