## 0. 背景

这是本科毕业设计《天线仿真开源软件集成与应用》的仿真环境。

链路分两段：

| 段 | 工具 | 用途 |
|---|---|---|
| 射频 | **openEMS**（FDTD 全波求解器） | 馈源全波仿真 |
| 结构 | **FEniCSx**（有限元） | 反射面面板变形 |
| 胶水 | **Python** 科学计算栈 | 自研射线追踪 / 物理光学积分 |

**环境的关键约束：FEniCSx 不能在原生 Windows 上跑**（缺 petsc4py 的 win-64 包，
且表单编译需要 MSVC）。必须装在 WSL2 的 Ubuntu 里。openEMS 同理，在 Linux 下
编译最省事。

因此目标结构是：

```
Windows 侧：Python 虚拟环境（跑自研 GO/PO 代码）
WSL 侧：openEMS v0.37 + FEniCSx dolfinx 0.11
```

## 3. 步骤

### 3.1 Windows 侧 Python 环境

```powershell
cd <项目根目录>
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip -i https://pypi.tuna.tsinghua.edu.cn/simple
.\.venv\Scripts\python.exe -m pip install numpy scipy matplotlib h5py pyyaml pytest -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> 如果项目里已有 `requirements.txt`，优先用它安装。

**验证**：

```powershell
.\.venv\Scripts\python.exe -c "import numpy,scipy,matplotlib,h5py,yaml,pytest; print('OK')"
```

### 3.2 安装 WSL2 + Ubuntu 22.04

**需要管理员权限。** 脚本在 `scripts\install-wsl-openems.ps1`，也可手动：

```powershell
Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux -All -NoRestart
Enable-WindowsOptionalFeature -Online -FeatureName VirtualMachinePlatform -All -NoRestart
# 重启后
wsl --set-default-version 2
wsl --install -d Ubuntu-22.04
```

首次运行 `ubuntu2204.exe` 设置 UNIX 用户名和密码（密码不显示字符，正常）。

**验证**：

```powershell
wsl -l -v          # 应看到 Ubuntu-22.04，Version 2
wsl --version      # WSL 安装包版本
```

### 3.3 openEMS

项目里 `scripts\bootstrap-ubuntu.sh` 会按顺序调用 `fix-openems-clone.sh`、
`finish-openems-submodules.sh`、`build-openems.sh`、`install-fenicsx-conda.sh`。
**优先直接跑它**：

```powershell
wsl -d Ubuntu-22.04 -- bash -lc "cd /mnt/<盘符>/<项目路径> && bash scripts/bootstrap-ubuntu.sh"
```

若脚本不可用，按下面的手动步骤。

#### 3.3.1 编译依赖

```bash
sudo apt-get update
sudo apt-get install -y build-essential cmake git wget curl \
  libhdf5-dev libboost-all-dev libcgal-dev libvtk9-dev libtinyxml-dev \
  python3-dev python3-pip python3-venv
```

> `libvtk9-qt-dev` 只有编译 GUI 才需要，见 4.2。

#### 3.3.2 拉源码（**必须走镜像**）

GitHub 直连经常在 `git clone` 时 `RPC failed / early EOF`。用镜像：

```bash
git clone --depth 1 https://gh-proxy.com/https://github.com/thliebig/openEMS-Project.git ~/openems-src
cd ~/openems-src
git -c url."https://gh-proxy.com/https://github.com/".insteadOf="https://github.com/" \
    submodule update --init --recursive --force
```

**拉完必须检查子模块工作区是否为空**（见 4.1）。

#### 3.3.3 编译安装（不需要 sudo）

```bash
cd ~/openems-src
./update_openEMS.sh --njobs=$(nproc) --python --disable-GUI --skip-dep-check ~/openems-install
```

说明：
- `--njobs=N` 是正确写法，**不是 `-j N`**
- `--disable-GUI` 跳过 AppCSXCAD，避开 `libvtk9-qt-dev`
- `--python` 会建 `~/openems-install/venv` 装 Python 绑定

#### 3.3.4 环境变量

追加到 `~/.bashrc`：

```bash
export PATH="$HOME/openems-install/bin:$PATH"
export LD_LIBRARY_PATH="$HOME/openems-install/lib:${LD_LIBRARY_PATH:-}"
export CMAKE_PREFIX_PATH="$HOME/openems-install:${CMAKE_PREFIX_PATH:-}"
```

**验证**：

```bash
source ~/.bashrc
openEMS --version
source ~/openems-install/venv/bin/activate
python -c "from CSXCAD import ContinuousStructure; from openEMS import openEMS; print('bindings OK')"
```

### 3.4 FEniCSx

**不要用 pip**：`fenics-dolfinx` 在 PyPI 上不存在（HTTP 404）。只能用 conda-forge。

```bash
# 从清华镜像装 Miniforge
curl -L -o ~/miniforge.sh \
  https://mirrors.tuna.tsinghua.edu.cn/github-release/conda-forge/miniforge/LatestRelease/Miniforge3-Linux-x86_64.sh
bash ~/miniforge.sh -b -p ~/miniforge3

~/miniforge3/bin/conda create -y -n fenicsx -c conda-forge \
  python=3.11 fenics-dolfinx fenics-basix fenics-ufl fenics-ffcx \
  petsc4py mpi4py mpich pyvista gmsh numpy scipy matplotlib h5py meshio
```

conda 的包名可能与上面略有出入（如 `fenics-ufl` 版本号），以 `conda search` 为准。
如果 conda-forge 直连慢，可换清华 anaconda 镜像。

**验证**：

```bash
PY=~/miniforge3/envs/fenicsx/bin/python
$PY -c "import dolfinx, petsc4py, mpi4py; print('dolfinx', dolfinx.__version__)"
```

## 4. 已知坑（务必检查，按发生概率排序）

### 4.1 子模块「假完成」

**现象**：`git submodule status` 显示所有子模块都在正确 commit，
但目录里只有一个 `.git` 文件，源码没检出。

**原因**：克隆中断留下的残状态，`git submodule update` 会认为已完成而跳过。

**处理**：

```bash
cd ~/openems-src
git submodule update --init --recursive --force --checkout

# 若仍为空，逐个恢复
for d in CSXCAD AppCSXCAD QCSXCAD CTB fparser hyp2mat openEMS; do
  n=$(ls -A "$d" 2>/dev/null | wc -l)
  [ "$n" -le 1 ] && git -C "$d" checkout -f
done
```

**判据**：`CSXCAD/CMakeLists.txt`、`openEMS/CMakeLists.txt`、`AppCSXCAD/CMakeLists.txt`
三个文件都存在。

### 4.2 编译在 QCSXCAD 阶段失败

**报错**：`QVTKOpenGLStereoWidget.h: No such file or directory`

**原因**：缺 `libvtk9-qt-dev`。

**处理**：加 `--disable-GUI`（推荐）。确实需要图形界面时：

```bash
sudo apt-get install -y libvtk9-qt-dev
cd ~/openems-src && ./update_openEMS.sh --njobs=$(nproc) ~/openems-install
```

### 4.3 Python 绑定缺失

**现象**：`openEMS --version` 正常，但 `import CSXCAD` 报 `ModuleNotFoundError`。

**原因**：编译时没加 `--python`，只装了 C++ 部分。

**处理**：重跑构建，加上 `--python --python-venv-mode venv --python-venv-dir ~/openems-install/venv`。

### 4.4 FEniCSx 装不上

| 报错 | 原因 | 处理 |
|---|---|---|
| `No matching distribution found for fenics-dolfinx` | PyPI 上没有这个包 | 改用 conda-forge |
| `ModuleNotFoundError: petsc4py` | win-64 没有该包 | 必须装在 WSL/Linux |
| `Can not map ... to a basix type` | `ffcx` 与 `ufl` 版本不配对 | 用 conda 一起装，别单独 pip |
| `Microsoft Visual C++ 14.0 is required` | Windows 上 ffcx 需要 MSVC | 同上，改用 WSL |

### 4.5 PowerShell 脚本中文乱码

**现象**：`.ps1` 脚本报 `Unexpected token`，错误信息里中文变成乱码。

**原因**：Windows PowerShell 5.1 不把无 BOM 的 UTF-8 当 UTF-8 读。

**处理**：含中文的脚本必须存成 **UTF-8 with BOM**。

### 4.6 openEMS 端口 API

**报错**：`'ContinuousStructure' object has no attribute 'AddLumpedPort'`

**原因**：端口挂在 **FDTD 对象**上，不在 CSX 对象上。

```python
port = FDTD.AddLumpedPort(1, 50, start, stop, 'z', 1.0)
```

另外端口起止点必须**只沿一个坐标轴变化**，否则报
`only a 1D/line integration is allowed`。

### 4.7 GitHub / PyPI 慢或断

- Git：用 `gh-proxy.com` 镜像 + `insteadOf`
- pip：用 `-i https://pypi.tuna.tsinghua.edu.cn/simple`
- 大文件：可分段并行下载（参考项目里 `work\wsl-pkg\fetch_wsl_parallel.ps1`）
