# 误差账

> 论文第 7 章的材料：每条近似、每个离散化，偏差多大、往哪边偏、从哪来。
> 数字都有出处（台账编号或脚本），没有一条是估的。

## 三条要点

### 一、射频侧的精度是够的

前三行都是 1e-06 到 1e-15 量级，说明几何和积分器本身没问题。真正限制精度的是**遮挡台阶**（±0.01 dB）和**轴对称假设**（0.12 dB），都不是算法问题，是模型选择。

### 二、结构侧的误差是方法级的，不是数值级的

板弯曲那两行（5.4% / 26.6%）**不随网格加密改善**（40→80 只从 5.57% 到 5.43%）。这说明问题在边界条件，不在离散。论文里必须把这条写成「模型近似」而不是「数值误差」。

这也是为什么结构侧只能定位成灵敏度分析——5.4% 的模型偏差放在「量级估算」里无所谓，放在「精确预测」里就是硬伤。

### 三、Ruze 不能当万能判据

同一份代码，随机相位屏下 PO 与 Ruze 差 <1%，确定性低频变形下差 15%。差别不在公式，在**前提**。

论文里凡是用 Ruze 的地方，都要写清「随机、相关长度远小于口径」这个条件。反过来说，凡是用 FEniCSx 算出来的变形，一律用 PO 直接积分，不要过 Ruze。

## 怎么呈现

建议做成两张表：

1. **精度表**（前三行 + 遮挡台阶）——证明射频链路可信
2. **近似表**（后六行）——说明每条近似的代价和适用范围

第 2 张表比第 1 张重要，因为它才是答辩时会被问的。
