## 一、选题背景与意义

**背景**：电大尺寸反射面天线的仿真，长期被商业软件（CST / HFSS / GRASP）占着。授权贵、内存吃紧，学生和中小单位很难完整跑一遍。

**本文做什么**：把三个开源工具串成一条完整链路——

```
openEMS（FDTD 全波）算馈源  →  自研 GO/PO 算远场  →  FEniCSx 算面板变形
                                       ↑                        │
                                       └──── 变形折成相位 ←──────┘
```

**意义**：链路每一段都对上解析解或教科书公式，且全部可复现（一条命令）。这件事公开文献里还没人做过（依据：`docs/06-反射面开源链路文献核查.md`，结论是「链路空白」）。

## 二、国内外研究现状

分三组写（材料在 `docs/06`）：

1. **方法链**：混合全波 + 高频近似（Le Lepvrier 2014 的 DG-FDTD+IPO）；结构-电磁耦合（Zhang 2013 的 FEM→相位→远场、Wang Wei 2023 的双反射面相位误差）
2. **商业链**：Du 2016（CST + GRASP-10 + 实测孔径效率）、Valente 2024（GRASP + CHAMP 3D）——唯一有实测验证的完整样板
3. **开源单点**：openEMS、PyPO、Dual Reflector Designer 各自成立，**没人把它们接起来**

结论段：空白在「开源 + 端到端 + 可复现」这一维。

## 三、研究内容

四块：

1. **射频链路**：卡塞格伦几何、射线追踪、口径幅度守恒、PO 积分；四道验证闸（Airy / 共焦 / 幅度守恒 / 遮挡）
2. **馈源**：openEMS 全波算销钉馈电喇叭；与解析 `cos^q` 对照；溢出效率与 q 的联合优化
3. **结构耦合**：FEniCSx 板弯曲 → 变形场 → 口径相位 → 远场；与 Ruze 公式对照、量级分析
4. **误差账**：每条近似的偏差、方向、来源（材料在 `docs/08`）

## 四、技术路线与方案

按链路顺序写，每段给判据。**关键数字直接引用，都核过**：

| 环节 | 判据 | 实测 |
|---|---|---|
| 均匀口径远场 | 解析 Airy | 7.0e-06 |
| 卡塞格伦共焦 | 近焦点 = F、等光程 | 4.4e-16 / 7.1e-15 |
| 口径幅度守恒 | `ρ = 2MF·tan(θ/2)` | 5e-15 |
| 绝对增益 | η 预算 | 20λ **31.24 dBi**（理想 35.96） |
| 馈源优化 | q 扫描 | 最优 q≈47，**+3.65 dB**，平台 47–64 |
| 结构耦合 | 变形 → 相位 → PO | 2 mm 板 **−0.014 dB** |

## 五、可行性分析

- **环境**：openEMS v0.37.0（Windows 原生，官方预编译包）、dolfinx 0.11.0、Python 3.11 都已装好并验收
- **算力**：轻薄本（12 核 16 线程、15.6 GB）够用。全波一次 10 GHz 算例 4–5 分钟；PO 一次算例 4 秒
- **已有基础**：58 条测试全过；全波馈源、结构变形都已接进流水线
- **风险**：论文写作时间（考研到 12 月 20 日，之后 4 周）
