## 二、章节结构

### 第 1 章 绪论

- 背景：电大尺寸反射面天线的仿真受商业软件授权和内存限制
- 研究现状：三组（方法链 / 商业链 / 开源单点），直接引 `docs/06` 的表
- 本文工作：链路 + 四道验证闸 + 误差账

数据：`docs/06`。

### 第 2 章 理论基础

- 几何光学（GO）与物理光学（PO）的适用条件
- 卡塞格伦双反射面的几何关系：共焦条件、等效焦距 `M·F`、口径半径 `ρ = 2MF·tan(θ/2)`
- 口径场幅度 `A = g·cos²(θ/2)/(M·F)` 的推导（**这段值得单独写一节**，它是 C-11 的地基）
- 效率预算：溢出 × 口径 × 遮挡，方向性 `D = 4π|∫A dA|²/(λ²∫|A|²dA)`
- Ruze 公式 `G/G₀ = exp(−σφ²)` 及其**适用条件**（随机相位、相关长度远小于口径）

数据：`src/go_po/*.py` 的 docstring、`docs/01-技术路线.md`。

### 第 3 章 开源工具链与集成架构

- openEMS：FDTD 全波，销钉馈电喇叭，导出近远场方向图（`examples/openems/`）
- FEniCSx：板弯曲（双泊松串联），导出变形场（`src/fenics/plate_bending.py`）
- 自研 GO/PO：射线追踪 + 口径积分（`src/go_po/`）
- 集成方式：YAML 配置驱动，`run_pipeline.py` 一条命令跑完
- 环境：Windows 原生 + WSL 双路；openEMS 也可用官方预编译包

数据：`examples/openems/README.md`、`docs/02-环境搭建.md`。

### 第 4 章 射频链路实现与验证

四道验证闸，**每一道都要给数字**：

| 闸 | 判据 | 实测 |
|---|---|---|
| 均匀口径远场 | 解析 Airy | 7.0e-06 |
| 卡塞格伦共焦 | 近焦点 = F、等光程 | 4.4e-16 / 7.1e-15 |
| 口径幅度守恒 | `ρ = 2MF·tan(θ/2)` | 5e-15 |
| 遮挡 | 场幅比 vs 功率 | −0.48 dB / −0.22 dB |

再加绝对增益预算：20λ **31.24 dBi**（理想 35.96），fd05 29.65 dBi。

数据：`work/进度台账.md` 的 W-0006 / W-0015 / W-0016。

### 第 5 章 馈源与副面的联合设计

- 溢出发射：q=8 时 64% 功率溢出，−4.49 dB（这个项以前被归一化吞掉）
- q 扫描：最优 q≈47 → 34.89 dBi，比 q=8 净增 **3.65 dB**
- 但 47 与 64 只差 0.05 dB，是**平台不是点**——按平台写
- 全波馈源对照：销钉喇叭 E 面 q≈8.1（正中假设）、H 面 q≈23；接进流水线后增益差 0.12 dB

数据：`work/scan_q.py`、`work/审查/2026-11-04-workbuddy.md`、`cases/cassegrain_horn_*`。

**这一章是全文最有分量的一节**，建议放在第 5 章而不是塞进附录。

### 第 6 章 结构—电磁耦合

- FEniCSx 板弯曲：双泊松串联，对 Navier 级数低 5.4%（边界条件近似，ISSUE-017）
- 变形 → 相位：`dφ = 2kw`
- 两种变形场对比：解析圆板 −0.018 dB vs 有限元方板 −0.015 dB
- **Ruze 只适合随机误差**：低频确定性变形下 PO 与 Ruze 差 15%（ISSUE-018）
- 灵敏度表：掉 0.5 dB 需 σ_w = 0.027λ（10 GHz 下 0.81 mm），是自重的 8 倍

数据：`work/coupled_demo.py`、`work/scan_surface_error.py`、`work/Ruze增益损失表.md`。

### 第 7 章 结果与讨论

### 第 8 章 结论与展望
