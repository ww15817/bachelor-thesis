# 第 2 章 理论基础（草稿）

> 正文草稿。这一章只放「后面要用到的东西」，不铺开讲天线理论全貌。

## 2.1 为什么用高频近似

反射面天线的口径通常是几十到几百个波长。全波方法（FDTD、FEM）在这个尺度上受内存限制——网格密度按 λ/20 算，一个 100λ 的反射面要上亿个单元。

高频近似的依据是：当结构尺度远大于波长时，局部的场可以用射线描述。几何光学（GO）给出射线的路径与幅度，物理光学（PO）把口径上的场积分成远场。代价是失去绕射效应（边缘衍射、后瓣），在近轴主瓣区影响很小。

本文的算例是 20λ 口径，GO/PO 已经足够；也正是因为口径大，GO/PO 才有意义。这个取舍写在第 3 章的工具分工里。

## 2.2 卡塞格伦的几何关系

双反射面由主面（抛物面）和副面（双曲面的一支）组成，两者共焦。

主面：`z = ρ²/(4F)`，口径半径 `R`。

副面用双曲面的实半轴 `a` 和半焦距 `c` 表示：

    a = (M−1)(F−L)/2
    c = (M+1)(F−L)/2
    e = c/a = (M+1)/(M−1)

其中 `M` 是放大率，`L` 是副面顶点到主面顶点 的距离。

**共焦条件**：近焦点在 `z = F`。这是定义性要求，也是第 4 章第一道验证闸的判据。

**等光程**：每条射线从远焦点出发、经副面和主面反射后，`r1 + r2 − z_main` 必须是常数，理论值 `F + 2a`。这条同样是第 4 章的判据，而且比共焦更强——它同时约束两条曲线的形状。

## 2.3 口径场的幅度：一个容易写错的式子

这一节的结论是第 4、5 两章的地基。

馈源发出的球面波经两次反射后到达口径。要算口径上的幅度，需要「能量守恒」这个约束：同一束射线管内的功率在传播中不变，所以

    |A|² dA = |g|² dΩ

其中 `g` 是馈源的电压方向图，`dΩ` 是立体角元。

关键在于 `dA/dΩ`。对**单抛物面**，焦点到反射面的距离是 `r = F/cos²(θ/2)`，于是 `1/r` 的扩散给出经典结果。但**双反射面不能照抄**——射线的等效扩散距离不是 `r1 + r2`。

正确的做法是从口径半径与张角的关系出发。卡塞格伦可以等效成一个焦距为 `M·F` 的抛物面，于是

    ρ = 2·M·F·tan(θ/2)

对 θ 求导：`dρ/dθ = M·F/cos²(θ/2)`，加上面积元的 `ρ dρ`，整理得

    dA/dΩ = (M·F)² / cos⁴(θ/2)

代入功率守恒：

    A(θ) = g(θ) · cos²(θ/2) / (M·F)

**这个式子的检验方式**：旧版写的是 `g/(r1+r2)`，边缘锥削给 −3.59 dB；新式给 −1.83 dB；而解析值 `cos⁴(θe)·cos²(θe/2)` 给 −1.91 dB。旧式差 1.7 dB，新式差 0.08 dB（网格外推的残留）。

这条推导值得在论文里完整写一遍——它是后面所有增益数字的来源。

## 2.4 口径远场积分

口径上的场分布为 `A(ρ,φ)`，远场由 Kirchhoff 积分给出：

    E(θ,φ) = ∫∫ A(ρ,φ) · exp(j k ρ sinθ cos(φ−φ₀)) · ρ dρ dφ

对均匀照明，这个积分有解析解（Airy 图案 `2J₁(u)/u`，`u = kR sinθ`）。这是第 4 章第三道闸的判据。

## 2.5 方向性与效率

方向性的定义是

    D = 4π U_max / P_rad

其中 `P_rad` 是**全部**辐射功率。写成口径场的积分形式：

    D = 4π |∫A dA|² / (λ² ∫|A|² dA)

注意分母是 `∫|A|²`，不是 `(∫A)²/A`。这个区别在第 4、5 章会反复出现——用错了会把遮挡算两遍。

口径效率拆成三项：

    η = η_spill × η_ap

- `η_spill`：馈源打到副面的功率比例，`1 − cos^(q+1)(θ_edge)`
- `η_ap`：口径上的效率，分子分母都只取未遮挡区

**溢出为什么算损失**：溢出的功率确实辐射出去了，但落在 17.76°~90° 的大角度上，不贡献轴向的 `U_max`，只进分母。按上面的定义，它必须算损失。

## 2.6 面板变形与相位

表面位移 `w` 会让光程改变 `2w`（往返各一次），于是口径相位扰动

    dφ = 2k·w = 4πw/λ

**Ruze 公式**：随机面板误差下

    G/G₀ = exp(−σφ²)

其中 `σφ` 是相位误差的 rms（弧度）。

**适用条件**：相位误差是随机的、相关长度远小于口径。确定性变形（比如整板挠曲）不满足这个条件——第 6 章会给出 15% 的偏差，那里必须用 PO 直接积分。

## 2.7 本章小结

四样东西：

1. 几何：共焦 + 等光程（第 4 章验证）
2. 幅度：`A = g·cos²(θ/2)/(M·F)`（第 4、5 章的增益来源）
3. 方向性：`D = 4π|∫A|²/(λ²∫|A|²)`（第 4、5 章的效率预算）
4. 相位：`dφ = 4πw/λ` + Ruze（第 6 章）

其余理论（绕射、边缘效应）本文不涉及，属于模型边界的范畴，写在第 7 章。
