# 附录 A 环境安装与复现步骤

> 附录草稿。目标是「另一个人拿到这个仓库，照着能跑出同样的数字」。
> 验证过：把已跟踪的文件导出一份到空目录，测试全过、算例逐位一致（台账 W-0028）。

## A.1 依赖清单

Python 3.11+，其余见仓库 `requirements.txt`：

```
numpy>=2.0          # np.trapezoid 是 2.0 起才有的
scipy>=1.11
pyyaml>=6.0         # config.py 直接 import yaml
matplotlib>=3.8
```

`pyproject.toml` 里也有同一份清单，两者要一致。

**numpy 的下界不能放松**：代码用了 `np.trapezoid`，1.26 上不存在。

## A.3 openEMS（馈源侧，可选）

两条路，选一条。

### 路一：Windows 原生（推荐）

1. 下载 `openEMS_x64_v0.37.0_msvc.zip`（GitHub releases）
2. 解压，记下含 `openEMS.exe`、`CSXCAD.dll` 的目录
3. 装 Python 绑定（zip 里 `openEMS/python/` 下，按 Python 版本选）：

   ```bat
   pip install h5py
   pip install --no-index csxcad-*.whl openems-*.whl
   ```

4. 设 `OPENEMS_ROOT` 指向那个目录

`_env.py` 会做 `os.add_dll_directory`。**这一步不能省**：Python 3.8 之后 PATH 不再参与扩展模块的 DLL 搜索，只加 PATH 一定报 `DLL load failed`。

跑：

```bat
cd examples\openems
python horn_pinfeed.py                        # 主模型，80x60 mm 口径
python horn_pinfeed.py --ax 29 --tag a58      # 换口径
```

单次 10 GHz 算例约 107×91×142 网格、4000 时间步，普通笔记本 4–5 分钟。输出 `data/feeds/horn_10ghz*.npz`。

### 路二：WSL 源码编译

适合需要改 openEMS 本身的场合。编译坑写在 `docs/02-环境搭建.md`，主要有两条：

- WSL 会把 Windows PATH 追加进 Linux PATH，CMake 可能命中 `/mnt/d/Anaconda` 的 Windows 版 HDF5，报 `ssize_t` 冲突。编译时用 `env -i` 净化 PATH
- 浅克隆没有 tag，`openEMS --version` 只显示裸哈希。要 `--deepen=200` 后重编

## A.4 FEniCSx（结构侧，可选）

用 conda（conda-forge）：

```bash
conda create -n fenicsx -c conda-forge dolfinx=0.11 petsc4py mpi4py python-gmsh
conda activate fenicsx
python src/fenics/check_env.py          # 探测环境
python src/fenics/plate_bending.py      # 板弯曲 + Navier 校验
```

预期：方板中心挠度对 Navier 级数低 **5.4%**（这是方法误差，不是 bug，见第 6 章）。

`dolfinx 0.11` 的 `LinearProblem` 必须给 `petsc_options_prefix`，否则报 `missing 1 required keyword-only argument`。

## A.5 完整链路

把全波馈源和结构变形都接进去：

```powershell
python run_pipeline.py cases\cassegrain_horn_e.yaml      # 全波馈源（E 面）
python run_pipeline.py cases\cassegrain_horn_h.yaml      # 全波馈源（H 面）
python run_pipeline.py cases\cassegrain_structure.yaml   # 加结构变形
```

对应的 YAML 段：

```yaml
feed:
  source: npz
  file: data/feeds/horn_10ghz_a80b60.npz
  plane: E

structure:
  enabled: true
  file: data/feeds/plate_deflection_2mm.npz
  lambda_m: 0.030
```

## A.7 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: yaml` | requirements 没装 pyyaml | 按 A.1 装 |
| `AttributeError: np.trapezoid` | numpy < 2.0 | 升级 numpy |
| openEMS `Prad ≈ 0` | 波导口 `a/b` 传了毫米 | 传米（见第 3 章踩坑表） |
| openEMS S11 ≈ 0 dB | 喇叭斜面旋转符号反了 | 见第 3 章踩坑表 |
| `ImportError: DLL load failed` | 没做 `add_dll_directory` | 见 A.3 |
| `dolfinx` `petsc_options_prefix` | 0.11 API 变更 | 按 A.4 加参数 |
| 遮挡场幅损失每次不一样 | 网格环与遮挡半径的相对位置 | 正常，只到 ±0.01 dB |

## A.8 复现口径

所有数字都是「跑一遍就该一样」。如果不一样，先查两件事：

1. 是不是用了未提交的改动（`git status`）
2. numpy 版本是不是 2.x

这两条排除之后还有差异，那才是真问题。
