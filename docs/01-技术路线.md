# 技术路线

## 1. 问题定义

电大尺寸反射面天线（口径 D = 20λ）若用 FDTD/FEM 直接全波仿真：

- 网格尺寸受限于 λ/10 ~ λ/20，口径方向需数千格点；
- 三维网格数按 D^3 增长，内存与时间开销不可接受；
- 工程上真正关心的（方向图、增益、副瓣、效率）并不需要完整近场细节。

因此把问题**拆成两个尺度**：

- **小尺度（馈源）**：仍用全波，因为它尺寸小、结构复杂，必须精确；
- **大尺度（反射面）**：用高频近似（GO/PO），只跟踪射线/面电流，不做体网格。

## 2. 双域链路

### 2.1 射频域

```
openEMS (FDTD)
    └─> 馈源近场 / 口径场  E_feed, H_feed
            └─> 自研 GO/PO 积分
                    ├─ GO: 馈源 -> 副反射面 -> 主反射面 的射线路径与幅度
                    └─ PO: 反射面等效面电流 J = 2 n x H_inc
                            远场   E(r) ~ jk/(4pi r) * integral J exp(jk r_hat . r') dS
```

**几何光学 (GO)**：用射线追踪建立馈源到副面、副面到主面的映射，
按能量守恒（射线管守恒）给出主面上的等效入射场幅度和相位。

**物理光学 (PO)**：在反射面表面取等效面电流，做面积分得远场。
PO 相比 GO 能给出更接近真实的副瓣与绕射结构。

### 2.2 结构域

```
FEniCSx (线弹性有限元)
    └─> 反射面面板在自重/风载/装配力下的变形 w(x,y)
            └─> 表面误差 -> 口径相位扰动  dphi = 2k * w
                    └─> 回代到 GO/PO 积分（相位项）
```

这条耦合是本题**区别于纯电磁仿真**的地方：
结构变形最终体现为口径上的相位误差，进而改变方向图（增益下降、副瓣抬高）。

## 3. 统一算例：20λ 卡塞格伦天线

| 参数 | 符号 | 取值 |
|---|---|---|
| 工作波长 | λ | 1.0（归一化） |
| 主反射面口径 | D | 20λ |
| 副反射面口径 | d | 2 ~ 3λ |
| 主面焦径比 | F/D | ~0.4 |
| 馈源 | - | openEMS 建模的角锥喇叭 |

选卡塞格伦的原因：双反射面几何明确、解析解可校验、工程上典型。

## 4. 验证方案

分三层，逐层验证再串联：

1. **GO/PO 自研代码**：先用标准抛物面（无副面）验证，与解析口径场结果对比；
2. **openEMS 链路**：用小口径（如 5λ）做全波，与 GO/PO 结果对比，确认误差来源；
3. **结构耦合**：FEniCSx 对薄板/壳变形做基准算例（如均布载荷圆板），与解析解对比。

## 5. 关键技术难点

| 难点 | 说明 | 对策 |
|---|---|---|
| 共形网格与面积分 | 反射面是曲面，积分要准确 | 参数化曲面 + 高斯积分 |
| 遮挡与二次反射 | 副面遮挡、边缘绕射 | 射线遮挡判决 |
| 电大尺寸积分效率 | 面元数量大 | 向量化 / 多尺度积分 + 分组 |
| 结构-电磁耦合 | 变形 -> 相位 | 位移场插值到口径面 |
| 数值一致性 | 两工具单位/坐标约定 | 统一在 `src/common` 约定 |

## 6. 创新点（可写进论文）

1. **全开源**：openEMS + FEniCSx + 自研积分，不依赖商业软件（HFSS/FEKO）；
2. **双域耦合**：把结构变形量化成口径相位误差，回代电磁远场；
3. **可复现**：统一算例 + 脚本化流程 + 分层验证。

## 6.1 结构侧的定位（2026-11-04 定）

20λ 口径（10 GHz 下 600 mm）配典型面板公差，增益变化在 0.01 dB 量级——这个量级撑不起「结构变形导致性能显著退化」的叙事。所以结构侧不以单点结果呈现，改为**灵敏度分析**：

- 给定表面误差 rms 从 0 扫到 0.06λ，给出增益损失曲线与反解表（掉 0.5 dB 需 0.81 mm，即自重量级的八倍）
- 结论写成「这台天线对面板公差有多敏感、公差该定到什么水平」，而不是「我算出了一个真实天线的变形」
- 随机表面误差**不会抬高第一副瓣**（实测随误差增大反而下降），所以副瓣不能当卖点
- 口径放大到 100λ 以上才看得到 0.5 dB 量级，那件事放展望——也正是在那里，GO/PO 省内存的优势才真正兑现

这不是回避。量级本身就是结论：20λ 这个尺度上，结构效应对增益的影响小于馈源和遮挡带来的一阶效应。

## 6.2 馈源 q 的选择（2026-11-05）

原来的 q=8 是配错的：馈源波束比副面张角（17.76°）宽出一大截，**64% 的功率打在副面外面**，折 −4.49 dB。这一项以前被 `∫A dA` 归一化吞掉了，账上完全看不到。

扫 q（增益按方向性定义 `D = 4π|∫A dA|² / (λ² ∫|A|² dA)` 算，分子分母都只取未遮挡区）：

| q | 溢出发射 | 总效率 | 绝对增益 |
|---|---|---|---|
| 8 | −4.49 dB | 0.3372 | 31.24 dBi |
| 16 | −2.49 dB | 0.5299 | 33.21 dBi |
| 32 | −0.97 dB | 0.7267 | 34.58 dBi |
| **47** | −0.44 dB | **0.7815** | **34.89 dBi** |
| 64 | −0.19 dB | 0.7713 | 34.84 dBi |
| 96 | −0.04 dB | 0.6790 | 34.28 dBi |

**最优 q ≈ 47，34.89 dBi**，比 q=8 净增 **+3.65 dB**。

但 q=47 与 q=64 只差 **0.05 dB**，这是个**平台不是一个点**。论文里按平台写——「q 取 40~70 均可，建议 50 左右」——别给单点最优，0.05 dB 在模型不确定度以内，答辩被问「凭什么正好 47」答不上来。

机理很清楚：q 加大让溢出降下来，但边缘锥削变深、口径效率跟着掉，两者在 q≈50 附近平衡。

写论文时这一节比「遮挡损失」有分量得多——它是「馈源与副面的联合设计」，能直接讲清为什么馈源不能随便配。

## 8. 已验证的物理判据（写论文可直接引用）

| 判据 | 期望 | 实测 |
|---|---|---|
| 卡塞格伦近焦点位置 | = F | 8.000000 λ（精确） |
| 出射方向平行于视轴 | 0 | 4.4e-16 |
| 等光程 r1+r2-z_main | 常数 | 起伏 7.1e-15 |
| 均匀圆口径远场 | 解析 Airy | 误差 7.0e-06 |
| 结构相位误差 -> 增益损失 | Ruze 公式 `exp(-σφ²)` | 偏差 0.001 dB |
| 副面遮挡（场幅比） | `20log10(1-ε)` | −0.437 dB（数值 −0.48，差 0.04 来自锥削） |
| 副面遮挡（功率等效） | `10log10(1-ε)` | −0.219 dB（数值 −0.234） |

> 遮挡这件事有两个数，别混：`20log10(1-ε)` 是**场幅比**，`10log10(1-ε)` 才是**增益**。
> 论文里写「遮挡增益损失 −0.48 dB」会被按 `D = 4πU_max/P_rad` 复算的人抓住差 0.26 dB（多了个平方）。
